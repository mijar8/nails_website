## 🚀 Как запустить локально

### Вариант 1: Без терминала (самый простой)
Просто откройте `index.html` двойным кликом в любом браузере (Chrome, Edge, Firefox, Safari).

### Вариант 2: Через локальный сервер
```bash
npm run dev
# или
npx serve . -l 3001
```
После этого откройте в браузере: [http://localhost:3001](http://localhost:3001)

## ✏️ Как редактировать контент

1. **Тексты, цены и услуги:**
   - Откройте `js/translations.js`.
   - Внутри находятся блоки для трёх языков: `de` (немецкий), `ru` (русский), `en` (английский).
   - Чтобы изменить цену или добавить услугу, отредактируйте массив `services`.
   - Чтобы изменить вопрос/ответ в FAQ, отредактируйте массив `faq`.

2. **Фотографии галереи:**
   - Замените файлы в папке `images/` (`gal-1.jpg` – `gal-5.jpg`) своими фотографиями с сохранением названий.

## 🌐 Как опубликовать (Деплой)

Проект полностью статический, не требует сборки (`npm run build`) и готов к деплою в 1 клик на любой хостинг:
* **Vercel:** просто перетащите папку `NailsMollys` в дашборд Vercel или подключите GitHub.
* **Netlify:** перетащите папку в раздел "Sites -> Add new site".
* **Cloudflare Pages:** подключите репозиторий, укажите Build Command: *пусто*, Output Directory: `.`
